# Rearranging the room

You can move the tables around from the till itself, without going to the back office. Two tables
pushed together for a party of eight, a terrace opened for the summer, a section closed off — all of
it from the floor screen.

This is a manager task. If you are signed in as a cashier the button is not there.

## Getting in and out

On the floor screen, tap **Edit room**. Tap **Done** when you have finished.

There is no separate save. Every change is sent as you make it, so leaving the editor cannot lose
work — and if something does not save you will see a message saying so rather than a change that
only looks like it happened.

**You need a connection.** Taking orders works offline; rearranging the room does not, because two
tills reorganising the same room while disconnected would have no honest way to agree afterwards.

## Moving and resizing

Drag a table to move it. It snaps to a grid so rows line up without fiddling.

Select a table and drag one of the small squares around its edge to resize it. Tables cannot be made
smaller than a usable size.

If two tables overlap, both turn red. That is a warning rather than a refusal — sometimes you really
do want two tables touching — but it is worth a second look.

### From the keyboard

The plan works without a mouse, which matters on a till with a keyboard and no space for one.

| Key | Does |
| --- | --- |
| Tab | Move between tables |
| Arrows | Move the selected table |
| Shift + arrows | Move it further, in bigger steps |
| Alt + arrows | Resize it |
| R | Rotate it |
| D | Duplicate it |
| Space | Add it to the selection, to change several at once |

## Changing a table

Select a table and the panel on the right shows its **seats**, **shape** and **colour**.

Seats is how many people the table takes — it is what the floor screen shows and what the kitchen
ticket prints. Type the number and press Enter, or tap elsewhere.

Colour is yours to use however the room needs: by section, by server, by anything. It has no meaning
to the system.

### Changing several at once

Hold **Ctrl** (or **Cmd**) and tap to add tables to the selection, or press **Space** on a table you
have moved to with Tab. Then pick a colour — every selected table changes.

## Adding, copying and removing

**Add table** puts a new table in the nearest free space and scrolls to it, so you can see where it
landed on a busy floor. It takes the lowest unused number.

**Duplicate table** copies the selected table — its size, seats and colour — into free space beside
it. Faster than adding and re-typing for a row of identical tables.

**Delete table** removes it. A table with an open order on it should be cleared first.

## Floors

**New floor** creates an empty one. **Duplicate floor** copies the floor you are on, with all of its
tables — useful for a terrace that mirrors the dining room, or for setting up a seasonal layout you
can adjust rather than build. **Rename** renames the one you are on.
