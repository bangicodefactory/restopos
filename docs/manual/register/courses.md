# Courses

Courses are how you tell the kitchen what to cook **now** and what to hold back. A table ordering
starters, mains and a dessert is one bill and three courses, and the kitchen only sees a course once
you fire it.

## Start using courses on a table

Take the order as usual, then press **Add course**.

The lines already on the order become **course 1**, and an empty **course 2** opens for whatever you
add next. That is the normal way to work: order the starters, add a course, order the mains.

You do not have to use courses at all. An order with no courses behaves exactly as before.

## Move a line to a different course

Open the line's notes and pick the course. A combo's items follow their parent — you never have to
move them one at a time.

## Fire a course

Press **Fire course N**, either on the course heading or on the button above the totals. That course
goes to the kitchen and is tagged as fired; the others stay where they are.

Firing sends **only that course's** lines. Anything you have added to a later course is still waiting
and can be fired when the table is ready for it.

## Sending the whole order

Pressing **Send** despatches everything that has not gone yet, across all courses — so any course it
carried is marked fired.

Use this when the table is not being paced: a quiet lunch where everything can go at once.

## Tidying up

If you add a course and never put anything in it, it disappears when you leave the products screen,
and the remaining courses are renumbered. A course that has lines, or that has already been fired,
is never removed automatically.

## What prints

Both the kitchen ticket and the bill print a heading for each course with its lines beneath it:

```
-- Starters --
2  Bruschetta
-- Mains --
1  Sea bass
```

On an order with a single course no heading is printed — it would say nothing the ticket does not
already say.
